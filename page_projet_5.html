Projet de receuil des besoins

Dans le cadre de la compétence 5 : Identifier les besoins métiers des clients et des utilisateurs.

Résumé du projet :

Ce projet par groupe de cinq avait pour but de créer un site WEB à partir d'un document qui contenait les exigences du besoin du commanditaire du site.

- La première partie de ce projet avait pour but d'analyser le recueil des besoins du client, puis de commencer la phase de conception. Nous avons donc commencé par récupérer les informations importantes qui étaient dans les exigences du besoin du client et nous les avons retranscrites dans une synthèse (1ère image du carrousel), afin de réduire le temps passé à chercher les informations importantes et afin de s'assurer de n'avoir rien manqué. Nous avons ensuite créé une charte graphique selon les exigences du commanditaire du site (2ème image), ainsi que l'arborescence du site et la synthèse détaillée du contenu de chaque page (3ème image).

- La deuxième partie de ce projet avait pour but de réaliser le maquettage du site avec Figma (4ème image), nous avons créé chaque page, les liens qui permettaient à l'utilisateur de naviguer entre ces pages ainsi que ces mêmes pages au format mobile. Ce qui nous a permis par la suite de coder le site en HTML5 et CSS3, ainsi que son format mobile avec des media queries. Chaque membre du groupe s'occupait de créer une page et son format mobile, ainsi qu'une page "bonus", selon nos goûts et notre façon de coder. Enfin, nous avons réalisé un oral de présentation afin de faire un compte rendu au client et de faire une démonstration des fonctionnalités du site.

Acquis :

  • Aisance avec le HTML
  • Aisance avec le CSS
  • Utilisation des media query
  • Utilisation de Figma
  • Création de l'arborescence
  • Analyse des besoins

Outils et langages utilisés :

  • HTML5 / CSS3
  • Visual Studio Code
  • Figma
  • GitLab
  • Media Queries
