Projet de création d'un volume docker qui créé automatiquement des documentations PDF

Dans le cadre de la compétence 3 : Installer et configurer un poste de travail.

Résumé du projet :

Ce projet par groupe de cinq avait pour but de créer, à l'aide de deux générateurs et de Docker une documentation technique et une documentation utilisateur à partir de codes source en C.

- La première partie de ce projet avait pour but de créer deux générateurs de documentation, un générateur en PHP qui analyse chaque code source fourni et qui va créer un fichier HTML de documentation technique. Le deuxième générateur PHP va créer un fichier HTML de documentation utilisateur pour chaque code source.

- La deuxième partie de ce projet avait pour but de créer un troisième générateur qui grâce à un conteneur Docker et un script Bash va créer deux fichiers PDF avec les deux documentations au format HTML créées précédemment. Nous avons ensuite créé un deuxième script Bash qui avait pour but de regrouper les deux documentations PDF créées et les codes sources dans une archive qui sera renvoyée à l'utilisateur en fin de traitement. Enfin, nous avons créé un troisième script Bash (dernière image du carrousel) qui, grâce à un volume Docker qui englobait tous nos conteneurs, nous permettait d'automatiser le processus. L'utilisateur déposait les codes sources commentés et écrits en C, les documentations étaient créées, puis converties au format PDF avant d'être renvoyées dans une archive avec les codes source.

Acquis :

  • Aisance avec le PHP
  • Aisance avec le Bash
  • Utilisation de Docker
  • Création de documentation
  • Travail en grande équipe
