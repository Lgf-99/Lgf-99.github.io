Projet de création d'un programme qui complète automatiquement une grille de sudoku

Dans le cadre de la compétence 2 : Optimiser, qui consiste à appréhender et construire des algorithmes.

Résumé du projet :

Ce projet en binômes avait pour but de reprendre un code de jeu de sudoku que nous avions créé, puis de l'automatiser grâce à un algorithme de Backtracking.

- Pour créer le jeu de sudoku basique avec le langage C, j'ai commencé par créer un cahier de tests à effectuer sur le jeu de sudoku final. J'ai ensuite créé le corps du code ainsi que les en-têtes des procédures et des fonctions en pseudo-code. Ce qui m'a permis de coder le jeu de sudoku en langage C par la suite, puis j'ai effectué les différents tests que nous avions imaginés dans le cahier de test. Enfin j'ai documenté mon code avec Doxygen afin de créer une documentation utilisateur.

- Pour la partie automatisation, nous avons commencé par mettre en place un algorithme de Backtracking grâce au langage C pour compléter la grille de sudoku, puis nous avions pour but d'optimiser cet algorithme de Backtracking pour le rendre le plus rapide possible. Pour l'optimiser, nous avons créé des fonctions qui utilisaient des techniques de résolution de sudoku connues, comme le singleton évident ou la technique du singleton caché. Un autre but du projet était de créer deux programmes qui utilisaient une structure différente. (Sur la dernière image du carrousel, il y a les deux structures). La première structure était composée de la valeur de la case, un tableau de candidats (qui pouvaient être placés dans la case) et le nombre de candidats. La deuxième structure a les mêmes attributs que la première, mais le tableau de candidats est remplacé par un tableau de booléens où l'indice de la case correspondait à la valeur du candidat, si le booléen était à true, la valeur était candidate.

Acquis :

  • Création d'un cahier de test
  • Aisance avec le pseudo-code
  • Aisance avec le langage C
  • Aisance avec la récursivité et les algorithmes
  • Création de documentation
  • Travail en groupe
