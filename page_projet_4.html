Projet de Conception et implantation d’une Base de Données

Dans le cadre de la compétence 4 : Concevoir et mettre en place une base de données à partir d’un cahier des charges client.

Résumé du projet :

Ce projet en binôme avait pour but de créer une base de données à partir d'un diagramme de classe UML, de peupler cette base, puis d'effectuer des statistiques sur une partie de ces données

- La première partie de ce projet avait pour but d'écrire un script en SQL (3ème image du carrousel) sur SqlWorkbench pour créer la base de données et les différentes tables qui la constituent à partir d'un diagramme de classe UML. Une fois la création des tables terminée, nous avons écrit un script de peuplement des tables qui, à partir de fichiers CSV et grâce à la commande WbImport de SqlWorkbench, créait des enregistrements dans les tables pour chaque ligne des fichiers CSV (1ère image du carrousel). Ce script se chargeait de compléter les tables et de modifier certaines données afin de faire en sorte qu'elles soient cohérentes pour pouvoir effectuer des requêtes dessus plus facilement.

- La deuxième partie de ce projet avait pour but d'effectuer des statistiques à partir de nos tables. Nous avons choisi 6 variables statistiques qui sont des attributs des tables, puis nous avons imaginé une problématique à laquelle il fallait répondre grâce à l'étude de ces variables. Nous avons utilisé Python pour réaliser ces statistiques, la librairie Panda pour importer les données et la librairie Numpy pour les stocker. Nous avons ensuite mis en forme les données avant de les explorer grâce à différentes fonctions que nous avons codées en Python (centrer-réduire, régression linéaire multiple, coefficient de corrélation multiple, etc...) ainsi que des graphiques (2ème image du carrousel). Enfin, grâce à l'exploration des données que nous avions faite avec Python, nous avons pu répondre à la problématique et créer un rapport pour retracer tout ce que nous avons fait au cours de cette partie.

Acquis :

  • Aisance avec le SQL
  • Traduction d'un digramme UML
  • Import de données depuis des CSV
  • Statistiques avec Python
  • Rédaction de rapport
  • Travail en binôme

Outils et langages utilisés :

  • SQL
  • SqlWorkbench
  • WbImport
  • Python
  • Visual Studio Code
  • Numpy / Panda
